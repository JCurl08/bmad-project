Technique 1

Three Rounds of Stupid

dumb on purpose

Pinned to the corkboard: the deliberately silly first pass. The janitor didn't survive the scope cut, but the cube came out of this round.

  • Play as the dungeon janitor resetting puzzles, keys and pots after each hero passes through; each run a new hero makes a new mess.
  • The world is a Rubik's cube that gets reshuffled every run (Zelda-randomizer feel).
  • Abilities reset each run, but re-collecting them grants an improved version.
  • The final dungeon/boss is open from the start: very hard but beatable (speedrun/skill route).
  • Persistent meta-progression: each run unlocks equipment upgrades.
  • Core theme: entropy rules the world.
  • The cube twists mid-run (on a timer or on big events); players time or trigger twists to reach new areas.
  • The lore itself is entropy.
  • NPC races built like Lego figures: head/body/legs swap between races each run.
  • The seed's chaos level scales NPC dialogue chaos: helpful hints become cryptic in high-entropy seeds.
  • NPC body parts carry function: head = knowledge/hint, torso = role (merchant/quest/smith), legs = movement. Mismatches create comedy (a sage head on a goblin body gives wrong advice).
  • High-chaos dialogue shown as scrambled word tiles the player rearranges to decode hints.

The kernel you love

entropy theme+shuffling Lego-like pieces+map rearranged every run
  • Kernel: entropy theme + shuffling Lego-like pieces + map rearranged every run.
  • Unifying system: one ‘modular swap’ engine. Map faces, rooms and NPC parts are all built from interchangeable modules and shuffled by a seed.

Lego NPC part-swapper

Head = knowledge/hint · torso = role · legs = movement. Swap parts and see whether the advice can be trusted.

Shaping the run

  • Goal: each run should flow through the map very differently.
  • Scope math: 3×3 faces × 6 = 54 screens total. A concrete, bounded content budget.
  • Always start on the same cube face (fixed home/hub face).
  • NPC interactions reshape the map: the order you talk to them, your answers, and who you ignore all change the layout.
  • One-way gates close the world behind you (e.g. an item to lower safely down a cliff but not climb back).
  • Rival races: befriending one race angers its rival and locks their region for the run. A social one-way gate that also sets the route.

Technique 3

One Feature Only

If the game could keep just one mechanic, which would it be? Everything else goes dark.

The rearranging map
★ your pick
  • One Feature Only pick: the rearranging map is the single mechanic worth keeping.
  • Pattern: each face's ability works mostly on its home face and a little everywhere else (the Zelda dungeon-item rule, reusable across all 6 faces).
  • The cube is mostly random, but the player can subtly influence the shuffle.
  • Goal: the whole map is explorable, but very hard on the first run.
  • First-run difficulty layers: tougher enemies vs the starting arsenal, NPCs share only a little info, some gates/puzzles inaccessible.
  • Where you die biases the next shuffle (e.g. dying on a face pulls it nearer the start face). Death as steering.
