# Deeper progression and chaos

## Description

The Could tier: persistent friendship scores, kept gear, colour gain, rival races, word-tile dialogue, mid-run twists and rotating storms, and run currency. It is deferred outside the initiative's Done when, and is planned only if time remains after the final publish.

## Outcome

Long-term players have more to chase across many runs.

## Done when

1. Each capability that is built meets its success criterion in the spec, and the updated build is republished on itch.io.
2. A seed sweep after CAP-23 (twists) finds no softlocks.
3. Friendship scores and kept gear survive closing and reopening the browser tab.

## Boundaries

The Could tier only. The gags (Newton cameo, skeleton-key fingers) belong here as optional polish. The death-steered shuffle is a spec non-goal.
